Attention Is All You Need — what the transformer actually computes

Breaking down Vaswani et al., 2017 — the paper that introduced the transformer architecture.

Original abstract, condensed

A network built entirely on attention, with no recurrence or convolutions — trained faster than prior models because attention parallelizes where recurrence can't.

Self-attention, worked out

Every token produces a query Q, key K, and value V. A token's new representation is a weighted sum of every value, where weights come from comparing its query against every key.

the term stabilizes gradients as dk grows.

python 
def attention(Q, K, V):
    d_k = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)
    return softmax(scores) @ V

Key takeaway

Multi-head attention isn't about more capacity — each head specializes on a different relationship in the sequence.
